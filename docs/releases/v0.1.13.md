# DSH 大肥鱼 v0.1.13

## Windows

- 玻璃右键菜单改为**真正的分层透明**（70% 不透明度），保留圆角 + 渐变
- 字体：10pt 加粗、纯白、无描边
- 设置 / 材质 / 大小 / 会话子菜单在打开时应用同一套玻璃主题
- 全局快捷键 `Ctrl+Alt+H` 显示/隐藏挂件
- 托盘菜单增加“检查更新”
- “检查更新”优先读取 `version.json`，与单一版本源一致

## macOS

- **全线暂停研发**；本版本没有 macOS 应用代码改动
- `mac/package.json` 只跟随版本号到 0.1.13

## 说明

- WinForms 分层透明是整窗 alpha，文字也会一起半透明；要“背景透明 + 文字完全不透明”需要 WPF 自定义菜单
- 子菜单主题通过 `DropDownOpening` 和主菜单 `Opened` 双入口应用；如果仍有个别子菜单不透明，请带截图反馈

## 安装

- Windows：解压后运行 `install.cmd`
- macOS：见 `mac/README.md`（实验性、暂停）
