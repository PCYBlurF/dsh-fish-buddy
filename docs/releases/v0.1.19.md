# DSH 大肥鱼 v0.1.19

性能和稳定性批次。

## 性能

- core 会话扫描增加 5 秒缓存
- widget state 读取移到后台线程，UI Tick 只消费结果
- hit-test 矩形缓存，鼠标移动不再重复 `PointToScreen`
- state 没变时不再 `Apply-State`
- 拖拽改为原生 `Window.DragMove()`

- 插件存活判断在 pid 失效时回退真实进程检查
