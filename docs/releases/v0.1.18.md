# DSH 大肥鱼 v0.1.18

热修：修复挂件“卡死”问题。

## 修复

- 大 session 解压超过 32MB 时 core 反复重启，state 不更新
  - 解压上限 32MB → 256MB
- stale 误判
  - core warmup 20s → 120s
  - widget stale 12s → 30s
  - core 每 15 秒心跳写 state
- 多会话 completion 无限庆祝
  - 改用已见 completion ID 集合，每条只处理一次

## 验证

- 用户会话 state age 正常（3–8s）
- widget CPU 回落，responding=True
- 日志不再刷 `completion celebrate`
- `node --test` 7 pass

## 安装

- Windows：解压后运行 `install.cmd`
- macOS：见 `mac/README.md`（实验性、暂停）
