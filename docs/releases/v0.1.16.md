# DSH 大肥鱼 v0.1.16

这一版集中处理审查 issue 的第二批，并完成性能优化。

## 性能

- 移除气泡/地面/鱼形态的实时模糊阴影，改为静态渐变
- 常驻动画限制 30fps；待命、完成、出错、隐藏时停止循环动画
- 核显占用：工作态约 4.5%，待命约 2.5%
- 修复精灵布局 0×0 导致人偶不可见
