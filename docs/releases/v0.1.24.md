# DSH 大肥鱼 v0.1.24

新增提示音音量调节。

## 新增

- 右键菜单 → 设置 → **提示音音量**
- 档位：0% / 25% / 50% / 75% / 100%
- 实时生效，持久化到 `ui.json` 的 `soundVolume`
- 默认 80%

## 实现

- 提示音从 `System.Media.SoundPlayer` 换成 WPF `MediaPlayer`
- 使用 `MediaPlayer.Volume`（0–1）控制音量
- 关闭「提醒音」时仍然完全不播放

## 安装

- Windows：解压后运行 `install.cmd`
- 只想安装不启用：`install.ps1 -NoEnable`
