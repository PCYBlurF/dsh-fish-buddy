# DSH 大肥鱼 v0.1.11

这是最后一个版本；v0.1.0–v0.1.10 历史 release 保留，原计划的 0.2.0 合并版已取消。

## 诊断包

- `node bin/doctor.mjs --bundle` / `mac/doctor.sh --bundle`
- macOS 右键 → 设置 → **导出诊断包**
- 生成 `logs/dsh-fish-diagnostic-*.zip`，包含 doctor 报告、`state.json`、`config.json`、`mac/ui-mac.json` 和 `logs/*.log`
- 不包含 API Key、凭据文件和会话正文

## 签名与公证

- 新增 `mac/SIGNING.md`：Developer ID 签名、`notarytool` 公证、`stapler` 验收步骤
- 当前 macOS 版是源码 + npm Electron，没有打包 `.app`；正式分发需要 Apple Developer 证书和打包配置

## 平台状态

- Windows：稳定维护
- macOS：实验性，暂停研发

完整版本历史见 [`CHANGELOG.md`](https://github.com/PCYBlurF/dsh-fish-buddy/blob/main/CHANGELOG.md)。

## 安装

- Windows：解压后运行 `install.cmd`
- macOS：见 `mac/README.md`
