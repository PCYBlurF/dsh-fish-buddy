# DSH 大肥鱼 v0.1.14

## Windows

- **窗口位置自愈**：启动后检查所有显示器的工作区，窗口不在任何屏幕内时自动回到主屏右下角
- **托盘菜单修复**：圆角/透明延迟到布局完成后再应用，不再被裁成 36×4、只剩一条
- **退出语义**：主动“退出大肥鱼”写入 `quit.flag`，插件不会立刻补拉
- **插件看门狗**：每 15 秒检查 `widget.pid`，挂件异常退出自动补拉；DSH 启动时清除 `quit.flag` 并拉起

## macOS

- **全线暂停研发**；本版本没有 macOS 应用代码改动
- `mac/package.json` 只跟随版本号到 0.1.14

## 说明

- 看门狗和位置自愈都是本地插件/挂件逻辑，不依赖网络
- 如果挂件被手动拖到屏幕外，重启 DSH 或重启挂件即可回到右下角

## 安装

- Windows：解压后运行 `install.cmd`
- macOS：见 `mac/README.md`（实验性、暂停）
