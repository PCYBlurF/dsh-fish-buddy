# DSH 大肥鱼 v0.1.15

这一版是审查 issue 的第一批加固，主要修数据安全、更新链接、诊断隐私和启动稳定性。

## Windows

- **install/uninstall 不再截断 profile**：managed block 只有开始标记时直接报错退出，不写文件；备份名唯一，写入改为临时文件替换
- **检查更新链接校验**：只允许 `https://github.com/PCYBlurF/dsh-fish-buddy/releases/` 前缀，拒绝 `file://`/其他域；显式启用 TLS 1.2
- **诊断包脱敏**：`state.json` 改为 `state.redacted.json`，只保留 phase / 会话 id / running / turn / step / 进度计数，不含 title、cwd、todos、errorMessage、goal
- **插件启动锁后置**：disabled、依赖缺失、启动失败时不再永久锁死；15 秒看门狗保留
- **首次 Tick 宽限 20 秒**，stale 阈值按 `pollMs * 3 + 5s` 自适应，避免启动和 `pollMs>9s` 时的重启循环
- **会话候选配额**：每 workspace 最多 50 条、全局 200 条，避免 40 条子代理日志挤掉主会话
- **running 从全部主会话筛选**，`activeWindow` 只用于展示，长任务不再被判 idle
- README 修正 clone URL，明确“进度读取不联网；余额/更新会访问对应服务”
